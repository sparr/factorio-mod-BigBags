[spoiler=Description][b][size=150]Description[/size][/b]
For those who can lift heavy luggages, this mod increases the size of your main inventory, and lets you reach a lot further.

Extra inventory size is available via a dedicated technology, with five tiers.
There is a technology to increase reach distance, build distance and resource reach distance, also with five tiers.
There are extra tiers for worker robot cargo size, continuing the three the base game provides. If another mod has already extended that research, for instance Bob's Logistics or 5Dim's New Logistic, this mod leaves it alone rather than conflicting with it.

Independantly of any research, it also increases the default stack size for every item, and the default magazine size for every ammo. It can set the default logistic request amount too, so that entering a new item does not immediately order an entire oversized stack.

All of that is configurable from the mod settings screen, in the startup section. Set the stack factor to 1 if you only want the technologies. Set the default request amount to 0 to leave every item's own default alone. The running speed factor is 1 by default and only applies while the vanilla speed is untouched, so it will not fight another mod.
[/spoiler]
